# Status and evidence

This open-source snapshot consolidates development in one repository. It is not a new binary release. The website manifest remains the authority for the current installable beta; imported older binaries may predate the development source in this snapshot.

## Current product scope

Codex desktop on macOS is early access. Claude Desktop's Code tab is experimental and requires the normal Claude Code CLI subscription connection. OpenCode is not a currently supported distribution. Host-owned panel and invitation controls have limitations documented in the customer host guides.

## Evidence limits

The published beta63 was released on November 14, 2026 with passing recorded automated/package checks and a live learning evaluation. Full native beta63 acceptance remained pending.

The development source contains later work, including provisional work/concept graph updates. The November 16 full live evaluation failed its unchanged first-offer latency gate: 18.099 and 16.538 seconds against a 15-second gate. Lesson and adaptive-path checks passed. This is not a completed or release-ready learning milestone. Earlier pass results do not cover later source changes.

Two fresh users completing restart, hook approval and a first useful lesson have not been observed as part of this repository cleanup. Do not claim that study or improved retention/transfer has been established.

Private reports, raw prompts, learner records, internal journals and outreach material are excluded from the public source snapshot. Keep reproducible synthetic tests and concise limits here; a clean repository must not hide failed acceptance behind passing unit tests.
