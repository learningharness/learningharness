# LearningHarness beta

Early access on macOS with Node.js 22.19+, Codex desktop and an existing Codex connection. Claude Desktop Code support is experimental and requires the Claude Code CLI signed in with an active subscription. Follow the canonical install guide and current host requirements at https://learningharness.dev/install.md .

Review local hooks yourself and follow the full restart instructions. Installers are unsigned; do not disable macOS protections. Learning consumes additional host allowance. Learner memory stays local. Anonymous usage metadata is on by default when configured and can be turned off in Settings. Code, prompts and learning answers do not go to a LearningHarness backend.
