# Governance

LearningHarness was started by Arvind Murali, [arvindm1991](https://github.com/arvindm1991), who is the initial maintainer and release owner.

Anyone can propose an issue, contribute code, improve documentation or challenge a learning assumption. Small fixes can be reviewed directly. Changes to learning behavior, data boundaries, host permissions or public extension contracts should have a written proposal and evidence before merging.

The maintainer decides scope, reviews contributions and approves releases. Decisions should be explained in the issue or PR so future contributors can understand them. Maintainer access is not automatically granted for a contribution. Additional maintainers can be invited after sustained contributions and review work, with their scope recorded here.

Source and releases belong in one canonical repository: `learningharness/learningharness`. The former distribution repository is retained as a compatibility pointer. Existing website download URLs and checksums remain unchanged; new packages receive new versions.
